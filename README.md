## 🔍 Troubleshooting

### The file will not open
- Make sure you downloaded the correct Windows file
- If it is a ZIP file, extract it first
- Right-click the file and check that Windows sees it as an app or script

### Claude Code still does not show channels
- Run the patcher again
- Check that you selected the right install folder
- Close Claude Code before patching, then open it again

### Windows blocks the file
- Use the file from the GitHub page
- Check whether the file was fully downloaded
- If the file is still blocked, open its Properties panel and review the security settings

### The patcher cannot find Claude Code
- Make sure Claude Code is installed
- Look for the install folder in your Apps or Program Files area
- Try the path again if you moved Claude Code after installing it
